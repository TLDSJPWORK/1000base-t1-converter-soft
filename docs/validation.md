# 動作確認・テスト

## ホストテスト

ホストテストは、実際に生成したMDIOフレームをデコードして確認します。

- 全32 PHY × 全32レジスタ × read/writeのST・OP・PHY・REG
- 32ビットプリアンブル、書込みTA、読取り中のMDIO解放
- 全65536通りの読取り値と、TA不成立時の拒否
- MMDアドレス指定・データフェーズ、通信異常時の途中停止
- 範囲外アドレス・NULL出力ポインタの拒否
- Mirror解除、RGMII遅延の有効化・無効化、他ビットの保持

PIOの実時間動作、電気特性、USB通信、PHY初期化の実行順序、Ethernet転送はホストテストの対象外です。

## 実機での動作確認

2026年9月13〜14日に、Rev1.0基板2台を次の構成で接続して確認しています。

```text
Mac ── RJ45 ── コンバーター ── T1 ── コンバーター ── RJ45 ── Raspberry Pi
```

U203は一方をmaster（1–4=ON、2–3=OFF）、もう一方をslave（1–4=OFF、2–3=ON）に設定し、U205は通常動作側に設定しました。

### MDIOと役割設定

- PHYアドレス0：ID `2000a231`（DP83867）
- PHYアドレス8：ID `2000a284`（DP83TG720）
- U203の設定に対応して、PMA MMD1:0x834はmaster=`0xc001`、slave=`0x8001`
- ソフトウェアで役割を変更しない通常版で、U203の設定が反映されることを確認

### v0.3.0の起動設定と通信

通常版v0.3.0を両台で使用し、手動のレジスタ操作を行わずに起動した状態での結果です。

| 項目 | 結果 |
| --- | --- |
| 起動処理 | `Media config result: OK` |
| DP83867 CFG4 | `0x10b0`（Mirror無効） |
| DP83867 RGMIICTL | `0x00d3`（TX/RX遅延有効） |
| DP83867 RGMIIDCTL | `0x0077`（TX/RX各2.0ns） |
| DP83TG720 RGMII_DELAY_CTRL | `0x0000`（TX/RX遅延無効） |
| T1の役割 | U203のmaster／slave設定を維持 |
| リンク | 両基板の両PHYともlink up、Mac側1000BASE-T full-duplex |
| ARP | 対向機器を解決 |
| ping | 20送信・20受信、損失0%、平均0.653ms |
| TCP/22 | 対向機器へ接続成功 |

### 確認範囲

上記は基本的な双方向通信の確認です。長時間負荷、複数フレームサイズでの性能、
PHYエラーカウンタによる損失・CRC評価、MDC波形測定、温度・電源変動試験は含みません。
